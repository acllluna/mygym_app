# Bug Fixer playbook

## Mission
Identify, diagnose, and resolve defects in the Aura Fitness application.

## Responsibilities
- Reproducing errors in the local Vite server.
- Verifying React state updates and `localStorage` consistency.

## Best Practices
- Include steps to reproduce when describing a fix.
- Favor small, isolated commits for bug fixes.

## Key Project Resources
- `src/tabs/*.tsx`
- console logs for `AuraFitnessDB`

## Key Symbols
- `AuraFitnessDB`
