# Backend Specialist playbook

## Mission
Ensure the local data persistence layer is reliable and well-structured, supporting the front-end components.

## Responsibilities
- Implementing and updating `AuraFitnessDB`.
- Ensuring data schemas map correctly into `localStorage`.

## Best Practices
- Isolate data access logic from UI.
- Use strict TypeScript typing for all stored entities.

## Key Project Resources
- `src/db.ts`
- `src/types.ts`
