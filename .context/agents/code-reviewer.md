# Code Reviewer playbook

## Mission
Maintain high code quality standards and prevent technical debt.

## Responsibilities
- Reviewing React component designs.
- Checking TypeScript typings.
- Enforcing the use of functional components and hooks.

## Best Practices
- Look for potential state staleness and hook dependency warnings.
- Suggest abstractions for repeated UI patterns.
