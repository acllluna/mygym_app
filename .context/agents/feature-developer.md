# Feature Developer playbook

## Mission
Build new, user-facing features for Aura Fitness.

## Responsibilities
- Implementing new UI tabs and application workflows.
- Wiring new features to `AuraFitnessDB`.

## Best Practices
- Build responsive and accessible UI components.
- Leverage the existing component library pattern.
