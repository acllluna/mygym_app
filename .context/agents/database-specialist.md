# Database Specialist playbook

## Mission
Optimize and manage the underlying data storage for Aura Fitness.

## Responsibilities
- Ensuring efficient read/writes to `localStorage` using `AuraFitnessDB`.
- Designing schema migrations when app models change.

## Best Practices
- Keep storage keys consistent.
- Handle storage quotas and data cleanup.
